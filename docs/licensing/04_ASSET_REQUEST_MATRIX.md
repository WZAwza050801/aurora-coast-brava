# Asset Request Matrix — 第二轮沟通用

> 中文批注：授权方第一轮一定会问「你们要什么格式的资产」。把这张表直接发过去，能让你的技术对接一次到位，也能让对方判断交付成本。这张表也是我们**自己的资产规格说明书**——将来无论拿到哪个品牌的授权，格式需求都一样，所以它长期有效。

---

## A. 逐车请求（按优先级）

| 优先级 | 车型 | 我们要什么 | 用在哪 |
|---|---|---|---|
| 1 | [PRIMARY] | 1 套可驾驶 3D 模型（GLB 或 FBX） | 玩家可选 + AI 对手 + 车库转台 |
| 2 | [SECONDARY] | 同上 | AI 对手 + 车库转台 |
| 3 | [TERTIARY] | 同上 | 车库转台（后期可能进赛道） |

若只给一台，我们优先要 **1 号**。

---

## B. 我们需要的资产规格

### B1. 模型

| 项 | 要求 | 备注 |
|---|---|---|
| 格式 | **GLB**（首选）或 FBX | GLB 免去单位/轴向转换，我们有现成管线 |
| 三角面 | 30,000 – 60,000 | 高于 60k 我们也接（会做 LOD） |
| 材质 | **分开的材质槽**，不要烘成一张贴图 | 我们要在运行时换车漆、玻璃、轮胎、内饰、灯具 |
| 建议槽位 | paint / glass / rim / tire / trim / interior / light-red / light-amber / light-white | 槽名不强制，我们按几何命名自动分类 |
| 轮子 | **四个独立 pivot**，命名 `wheel_fl` / `wheel_fr` / `wheel_rl` / `wheel_rr` | 视觉轮由物理 WheelCollider 直接驱动，pivot 名不对我们会改 |
| 车身朝向 | 车头朝 **-Z**，地面 **y = 0** | 若朝向不同我们自行旋转，无需重出 |
| 车长 | 不限 | 我们统一归一到 **4.53 m** |
| 铰链件 | 可选：`bonnet` / `door-front-left` / `door-front-right` | 有的话车库可以做「开盖展示」，是加分项 |
| 贴图 | PBR（base color / normal / metallic-roughness），2K 或 4K | 若只有烘焙贴图也可以，我们会拆材质重上色 |

### B2. 非模型资产（可选，但有则更好）

| 项 | 用途 |
|---|---|
| 官方高清渲染图 / 官方摄影 | 车库里做背景板、商店页对比图 |
| 车辆规格表（尺寸、重量、动力、涂装选项） | 只作建模参考与文案；**不会**用真实性能数据做游戏内宣称 |
| 品牌标识（badge / 轮毂盖 / 贴花）的官方源文件 | 保证车标形态正确 |
| 商标使用规范（brand guidelines PDF） | 决定我们能不能做周边、能不能在 UI 上放标识 |

---

## C. 我们会遵守的规则（提前说清楚，减少对方顾虑）

1. **只用官方提供的标识**，不自造、不改形、不拉伸。
2. **不用于任何暗示真实性能/价格/在售状态的表述**。游戏内 HUD 不显示马力和极速这类真实数据。
3. **未经书面批准，不在任何公开材料中出现该车**（含截图、预告片、商店页、社媒）。
4. **不做负面呈现**：不做事故/撞毁/损伤贴图，不做警匪对抗叙事（若需要，统一按"赛事用车"处理）。
5. **不做竞品对比**：游戏内不出现与其他品牌的性能对比数值。
6. 车身涂装默认使用**品牌中性色**；若使用品牌官方赛车涂装（如真实赛事涂装），会先单独报批。

## D. 我们能提供的回报（谈判时用来换条件）

| 可给 | 说明 |
|---|---|
| 车库展示位 | 车库转台是每局比赛前的固定画面，曝光稳定 |
| 车型可玩 | 玩家可以真的开这台车，不只是展示 |
| AI 对手 | 每场 2–3 台在赛道上的持续曝光 |
| 商店页首屏 | 可给主视觉位（需按合同约定） |
| 社区内容 | 社媒发布计划可配合官方渠道联动 |
| 无恶意修改承诺 | 不做「撞烂 / 烧毁 / 涂鸦」类内容 |
| 本地化 | 可做中文本地化，面向中国市场（对中东品牌有额外价值） |

## E. 如果对方问「你们能保证什么」——三个必须写进合同的点

1. **审批时限**：写明「作品审阅回复期限 X 个工作日」，避免无限期等待卡住开发排期。
2. **交付格式与时机**：写明交付物、交付时间，以及**资产到位晚于开发排期时的处理方式**（例如顺延发布或先用占位车）。
3. **授权终止后的处理**：明确授权到期/终止后，已发行版本是否继续销售（业界惯例是已售版本可继续留存），以及素材是否需要下架。

> 这三条是 WIPO《Mastering the Game》里反复强调的「授权是权利清理，也是生产协同」——没有它们，一个以月计的审批周期会直接卡死你的排期。

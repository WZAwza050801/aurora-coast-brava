## 这封信的几个刻意设计

| 写法 | 为什么 |
|---|---|
| 第一段就点明「CAA 代表 McLaren，且 gaming 是你们的品类」 | 让对方 5 秒内知道这封信该转给谁，避免被当普通商务咨询 |
| 主动加了一句「如果 McLaren 的游戏授权在别的部门，请指给我正确的对口人」 | 2024 年底换了股东、2025 年新设了 McLaren Licensing，**很可能你已经找错了桌子**。这句既礼貌又专业，还顺带套出真实流程 |
| **不点名任何竞品** | 提 Asphalt 8 等于自曝「我们做了个竞品衍生」，会直接进入法务审查而不是商务通道 |
| 强调「展示车 = 赛车 = 营销素材是同一台车」 | 授权方评估舆情风险时最关心这一条 |
| 主动提出「先做一台车」 | 大牌授权的决策成本很高，把 scope 压到最小能显著提高过会概率 |
| 主动提出「接受创意审核流程」 | 授权方最怕的是车被画歪/开着上街/在泥里 |
| 给出技术契约（轮位 pivot、材质槽、面数预算） | 让对方美术团队能一次到位，少一轮邮件往返 —— 这是最能体现「专业」的细节 |
| 主动提供可试玩的 build | 这是你相对大厂的**唯一结构性优势**：你能立刻给人看到实机画面，不用走品牌方的审批流程 |
| 预算一栏先不给数字，只说「可以详谈」 | 授权方通常需要先内部过一轮预算门槛；但过早给数字会被当成低价锚点。等对方回复再谈。 |

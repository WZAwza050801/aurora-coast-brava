## Unity MCP 真正打通（此前结论错误）

昨天判定“Unity MCP 配不上”是错的——真实原因只是服务端进程从未启动。正确结构是两段：

```
WorkBuddy --HTTP /mcp--> mcp-for-unity (Python, 127.0.0.1:8080)
                                ^
                                | WebSocket /hub/plugin
                         Unity 编辑器插件（主动外连）
```

- 服务端源码 `Server/src/main.py`，`--transport stdio|http`，HTTP 默认 8080；路由 `/mcp`、`/hub/plugin`、`/health`、`/api/instances`。
- 插件偏好（注册表 `HKCU\Software\Unity Technologies\Unity Editor 5.x`）默认 `AutoStartOnLoad=false`、`UseHttpTransport=true`。必须手动把 AutoStartOnLoad 置 1，否则不会自动连。
- 批处理模式还要 `UNITY_MCP_ALLOW_BATCH=1`，源码里 `HttpAutoStartHandler` 会直接 return。

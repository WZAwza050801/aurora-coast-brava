# 2026-11-12

## Unity 编译彻底打通（今日最大突破）

卡了两天的 "Compiling Scripts" 挂起 / 批处理静默退出，根因链条终于查清：

1. **腾讯电脑管家**（SecurityCenter2 注册项）会钩住新建子进程做云查杀，把进程以
   `CREATE_SUSPENDED` 状态创建。本机沙箱代理网络不通 → 云查杀永不返回 → 子进程永久挂起。
   - 实测证据：`bee_backend` 下的 `cmd.exe /c netcorerun.exe ApiUpdater.MovedFromExtractor.dll ...`
     主线程 `Wait/Suspended`、无子进程；`ResumeThread` 后 `prev_suspend=1`。
   - **修复**：`tools/build_guard.py`（纯 ctypes Toolhelp32 快照），每 0.2s 扫描
     netcorerun/dotnet/bee_backend/ILPP 及 bee 下的 cmd，自动恢复挂起线程。
     必须**先启 guard 再启 Unity**，guard 用 run_in_background 任务挂着（bash `&` 分离会被宿主回收）。
2. **`Library/Bee/buildprogram0.traceevents` 删除被拒**（UnauthorizedAccessException）→ bee
   崩溃、批处理 exit 1、日志误导性显示 "Scripts have compiler errors"。每轮构建前删除
   `Library/Bee/*traceevents` 即可。
3. Unity `-logFile` 有缓冲，异常退出时尾部丢失 → 排查时用 `-logFile -` + `Tee-Object` 落盘才能看到真实错误。
4. 需要关沙箱执行（dangerouslyDisableSandbox），读 `D:\桌面\Unity Hub` 安装目录才行。
